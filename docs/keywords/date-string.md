# DATE$

**Status:** Not implemented - reference only  
**Category:** Date / time

Read a date string, or set it in dialects supporting date assignment.

## Syntax

```basic
DATE$
```

## Parameters

- No arguments when reading.

## Use cases

- Display a date in a legacy application.

## Examples

### Example 1 (reference)

```basic
PRINT DATE$
```
