# AND

**Status:** Supported  
**Category:** Operators

Bitwise AND of two rounded signed 16-bit values.

## Syntax

```basic
left AND right
```

## Parameters

- Operands: numeric expressions.

## Use cases

- Build arithmetic formulas or conditions.
- Trace how operands change the result.

## Examples

### Example 1 (program)

```basic
10 PRINT 6 AND 3
```

Expected output / effect:

```text
 2 
```

## Notes

- Both sides are evaluated; AND does not short-circuit. Parenthesize complex conditions.
