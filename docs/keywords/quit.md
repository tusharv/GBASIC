# QUIT

**Status:** Supported  
**Category:** Environment

Exit the programming environment; alias of SYSTEM.

## Syntax

```basic
QUIT
```

## Parameters

- No arguments.

## Use cases

- Close the environment from its command field.

## Examples

### Example 1 (shell)

```basic
QUIT
```

Expected output / effect:

```text
The environment exits.
```

## Notes

- This is an environment command, not a numbered BASIC statement.
