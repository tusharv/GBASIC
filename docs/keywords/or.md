# OR

**Status:** Supported  
**Category:** Operators

Bitwise OR of two rounded signed 16-bit values.

## Syntax

```basic
left OR right
```

## Parameters

- Operands: numeric expressions.

## Use cases

- Build arithmetic formulas or conditions.
- Trace how operands change the result.

## Examples

### Example 1 (program)

```basic
10 PRINT 4 OR 1
```

Expected output / effect:

```text
 5 
```

## Notes

- Both sides are evaluated; OR does not short-circuit.
