# RENUM

**Status:** Not implemented - reference only  
**Category:** Environment

Renumber source lines and eligible references.

## Syntax

```basic
RENUM [new] [, old] [, increment]
```

## Parameters

- new: new starting number.
- old: original starting line.
- increment: new gap.

## Use cases

- Make room for inserted source lines.

## Examples

### Example 1 (reference)

```basic
RENUM 10,0,10
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
