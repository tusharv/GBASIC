# PRINT#

**Status:** Not implemented - reference only  
**Category:** Files

Write formatted values to an opened BASIC file.

## Syntax

```basic
PRINT #number, expression [; expression ...]
```

## Parameters

- number: output file handle.
- expressions: values to write.

## Use cases

- Save a generated report.

## Examples

### Example 1 (reference)

```basic
PRINT #1, "Result", 42
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
