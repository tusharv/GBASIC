# PLAY

**Status:** Not implemented - reference only  
**Category:** Audio

Interpret a music macro string in supporting BASIC dialects.

## Syntax

```basic
PLAY music$
```

## Parameters

- music$: notes, durations and tempo commands.

## Use cases

- Play a short melody.

## Examples

### Example 1 (reference)

```basic
PLAY "T120 CDE"
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
