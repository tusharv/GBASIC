# PALETTE

**Status:** Not implemented - reference only  
**Category:** Graphics

Change a palette entry in supported legacy modes.

## Syntax

```basic
PALETTE [attribute, color]
```

## Parameters

- attribute: palette index.
- color: hardware-dependent color value.

## Use cases

- Change a graphics palette.

## Examples

### Example 1 (reference)

```basic
PALETTE 1, 4
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
