# ERROR

**Status:** Not implemented - reference only  
**Category:** Errors

Raise a BASIC error by its legacy code.

## Syntax

```basic
ERROR code
```

## Parameters

- code: valid error number for the target BASIC dialect.

## Use cases

- Test an error-handling path.

## Examples

### Example 1 (reference)

```basic
ERROR 5
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
