# PRINT USING

**Status:** Not implemented - reference only  
**Category:** Formatting

Format PRINT output with a legacy picture/template string.

## Syntax

```basic
PRINT USING format$; expressions
```

## Parameters

- format$: numeric/string formatting picture.
- expressions: values matching the picture.

## Use cases

- Print amounts with a fixed number of decimal places.

## Examples

### Example 1 (reference)

```basic
PRINT USING "###.##"; 12.5
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
