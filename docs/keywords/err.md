# ERR

**Status:** Not implemented - reference only  
**Category:** Errors

Read the code of the last trapped BASIC error.

## Syntax

```basic
ERR
```

## Parameters

- No arguments.

## Use cases

- Classify an error inside a handler.

## Examples

### Example 1 (reference)

```basic
PRINT ERR
```

## Notes
