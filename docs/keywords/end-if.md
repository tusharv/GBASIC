# END IF

**Status:** Not implemented - reference only  
**Category:** Structured control

Close a multiline QBasic IF block.

## Syntax

```basic
IF condition THEN
    statements
END IF
```

## Parameters

- No arguments; closes the corresponding multiline IF.

## Use cases

- Finish a structured conditional.

## Examples

### Example 1 (reference)

```basic
IF A>0 THEN
    PRINT A
END IF
```

## Notes

- Not implemented. Plain END/STOP and numbered GOSUB/RETURN are the current supported alternatives where applicable.
