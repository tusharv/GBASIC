# ATN

**Status:** Supported  
**Category:** Functions

Return the inverse tangent as an angle in radians.

## Syntax

```basic
ATN(number)
```

## Parameters

- number: numeric ratio or slope.

## Use cases

- Recover an angle from a slope.

## Examples

### Example 1 (program)

```basic
10 PRINT ATN(0)
```

Expected output / effect:

```text
 0 
```

## Notes

- This is a one-argument arctangent, not a two-coordinate atan2.
