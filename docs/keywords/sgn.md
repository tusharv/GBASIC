# SGN

**Status:** Supported  
**Category:** Functions

Return -1, 0 or 1 according to a number's sign.

## Syntax

```basic
SGN(number)
```

## Parameters

- number: numeric expression.

## Use cases

- Classify profit, zero or loss.

## Examples

### Example 1 (program)

```basic
10 PRINT SGN(-7)
```

Expected output / effect:

```text
-1 
```

## Notes

- The result describes the sign, not the magnitude.
