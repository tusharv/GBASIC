# LOCATE

**Status:** Not implemented - reference only  
**Category:** Terminal layout

Move the legacy text cursor to a row and column.

## Syntax

```basic
LOCATE [row] [, column]
```

## Parameters

- row/column: normally one-based text positions; additional cursor options are dialect-specific.

## Use cases

- Position labels in a text form.

## Examples

### Example 1 (reference)

```basic
LOCATE 5, 10
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
