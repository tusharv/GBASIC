# DEFINT

**Status:** Not implemented - reference only  
**Category:** Types

Set the default integer type for names beginning with a letter range.

## Syntax

```basic
DEFINT letter[-letter]
```

## Parameters

- letter range: initial letters affected by the declaration.

## Use cases

- Use integer defaults in a legacy module.

## Examples

### Example 1 (reference)

```basic
DEFINT A-Z
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
