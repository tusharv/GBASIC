# COLOR

**Status:** Not implemented - reference only  
**Category:** Terminal layout

Set legacy text/graphics colors using mode-specific arguments.

## Syntax

```basic
COLOR [foreground] [, background]
```

## Parameters

- foreground/background: palette indices appropriate for the active mode.

## Use cases

- Color a title or form.

## Examples

### Example 1 (reference)

```basic
COLOR 14, 1
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
