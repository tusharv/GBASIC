# EXIT

**Status:** Supported  
**Category:** Environment

Exit the programming environment; alias of SYSTEM.

## Syntax

```basic
EXIT
```

## Parameters

- No arguments in the environment command.

## Use cases

- Leave the classic prompt.

## Examples

### Example 1 (shell)

```basic
EXIT
```

Expected output / effect:

```text
The environment exits.
```

## Notes

- QBasic EXIT FOR, EXIT DO, EXIT SUB and EXIT FUNCTION are separate planned features and are not implemented.
