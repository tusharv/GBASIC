# KILL

**Status:** Not implemented - reference only  
**Category:** Files

Delete a file in a supporting BASIC filesystem.

## Syntax

```basic
KILL "filename"
```

## Parameters

- filename: file path or supported pattern.

## Use cases

- Remove a generated temporary file.

## Examples

### Example 1 (reference)

```basic
KILL "temporary.txt"
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
