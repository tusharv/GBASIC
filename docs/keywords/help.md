# HELP

**Status:** Supported  
**Category:** Environment

Show the keyword index or a detailed topic.

## Syntax

```basic
HELP [keyword]
```

## Parameters

- keyword: optional statement, function, operator or alias.

## Use cases

- Learn a keyword without internet access.

## Examples

### Example 1 (shell)

```basic
HELP PRINT
```

Expected output / effect:

```text
Syntax, parameters, use cases, examples and notes for PRINT.
```

## Notes

- F1 opens searchable help in the UI. Planned topics are marked Not implemented.
