# POINT

**Status:** Not implemented - reference only  
**Category:** Graphics

Read a graphics pixel color in its coordinate form.

## Syntax

```basic
POINT(x,y)
```

## Parameters

- x/y: pixel position; other classic forms are dialect-dependent.

## Use cases

- Inspect a collision or drawing pixel.

## Examples

### Example 1 (reference)

```basic
PRINT POINT(20,30)
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
