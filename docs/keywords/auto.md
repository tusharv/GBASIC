# AUTO

**Status:** Not implemented - reference only  
**Category:** Environment

Generate successive line-number prompts in a classic BASIC editor.

## Syntax

```basic
AUTO [start] [, increment]
```

## Parameters

- start: optional initial line.
- increment: optional gap between numbers.

## Use cases

- Enter numbered source interactively.

## Examples

### Example 1 (reference)

```basic
AUTO 10,10
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
