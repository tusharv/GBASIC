# DEF FN

**Status:** Not implemented - reference only  
**Category:** Functions

Define a single-expression user function in classic numbered BASIC.

## Syntax

```basic
DEF FNname(parameters) = expression
```

## Parameters

- name: function identifier after FN.
- parameters: formal variables for the expression.

## Use cases

- Name a reusable one-line formula.

## Examples

### Example 1 (reference)

```basic
DEF FNTWICE(X)=X*2
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
