# -

**Status:** Supported  
**Category:** Operators

Subtract numbers; prefix minus negates a value.

## Syntax

```basic
left - right
```

## Parameters

- Operands: numeric expressions.

## Use cases

- Build arithmetic formulas or conditions.
- Trace how operands change the result.

## Examples

### Example 1 (program)

```basic
10 PRINT 7-2;-2^2
```

Expected output / effect:

```text
 5 -4 
```

## Notes

- Exponentiation binds more tightly than unary minus; use (-2)^2 for positive four.
