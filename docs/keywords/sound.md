# SOUND

**Status:** Not implemented - reference only  
**Category:** Audio

Request a legacy tone with specified frequency and duration.

## Syntax

```basic
SOUND frequency, duration
```

## Parameters

- frequency: tone frequency in Hz.
- duration: legacy timing units; not implemented by the terminal bell.

## Use cases

- Play a simple note.

## Examples

### Example 1 (reference)

```basic
SOUND 440, 9
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
