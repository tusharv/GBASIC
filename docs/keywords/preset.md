# PRESET

**Status:** Not implemented - reference only  
**Category:** Graphics

Reset a pixel, usually to the background color when no color is supplied.

## Syntax

```basic
PRESET (x,y) [, color]
```

## Parameters

- x/y: pixel position.
- color: optional palette index.

## Use cases

- Erase a plotted point.

## Examples

### Example 1 (reference)

```basic
PRESET (20,30)
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
