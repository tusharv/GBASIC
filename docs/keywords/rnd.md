# RND

**Status:** Not implemented - reference only  
**Category:** Random numbers

Return a pseudo-random value; argument behavior is dialect-dependent.

## Syntax

```basic
RND[(argument)]
```

## Parameters

- argument: controls generator behavior in classic BASIC; reference only here.

## Use cases

- Choose a random game value.

## Examples

### Example 1 (reference)

```basic
PRINT INT(RND*6)+1
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
