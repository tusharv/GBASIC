# SCREEN

**Status:** Not implemented - reference only  
**Category:** Graphics

Select a legacy video mode; a function form exists in some dialects.

## Syntax

```basic
SCREEN mode
```

## Parameters

- mode: legacy screen-mode number; supported resolutions/palettes depend on hardware/dialect.

## Use cases

- Start a legacy graphics program.

## Examples

### Example 1 (reference)

```basic
SCREEN 12
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
