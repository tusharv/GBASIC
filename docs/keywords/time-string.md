# TIME$

**Status:** Not implemented - reference only  
**Category:** Date / time

Read a time string, or set it in dialects supporting time assignment.

## Syntax

```basic
TIME$
```

## Parameters

- No arguments when reading.

## Use cases

- Display a clock string.

## Examples

### Example 1 (reference)

```basic
PRINT TIME$
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
