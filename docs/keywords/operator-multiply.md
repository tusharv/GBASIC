# *

**Status:** Supported  
**Category:** Operators

Multiply numeric values.

## Syntax

```basic
left * right
```

## Parameters

- Operands: numeric expressions.

## Use cases

- Build arithmetic formulas or conditions.
- Trace how operands change the result.

## Examples

### Example 1 (program)

```basic
10 PRINT 3*4
```

Expected output / effect:

```text
 12 
```

## Notes

- Multiplication precedes addition. Strings cannot be multiplied.
