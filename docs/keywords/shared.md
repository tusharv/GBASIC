# SHARED

**Status:** Not implemented - reference only  
**Category:** Scope

Share a variable between module code and procedures.

## Syntax

```basic
DIM SHARED name
SHARED name
```

## Parameters

- name: variable or array to share.

## Use cases

- Share application state across procedures.

## Examples

### Example 1 (reference)

```basic
DIM SHARED SCORE AS INTEGER
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
