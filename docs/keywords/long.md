# LONG

**Status:** Not implemented - reference only  
**Category:** Types

Name QBasic's signed 32-bit integer type.

## Syntax

```basic
DIM name AS LONG
```

## Parameters

- name: a long-integer variable.

## Use cases

- Store whole-number counts larger than 16-bit range.

## Examples

### Example 1 (reference)

```basic
DIM COUNT AS LONG
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
