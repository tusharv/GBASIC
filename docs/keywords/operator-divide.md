# /

**Status:** Supported  
**Category:** Operators

Divide numeric values, preserving a fractional result.

## Syntax

```basic
left / right
```

## Parameters

- Operands: numeric expressions.

## Use cases

- Build arithmetic formulas or conditions.
- Trace how operands change the result.

## Examples

### Example 1 (program)

```basic
10 PRINT 7/2
```

Expected output / effect:

```text
 3.5 
```

## Notes

- A zero divisor raises Division by zero.
