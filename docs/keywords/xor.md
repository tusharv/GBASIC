# XOR

**Status:** Supported  
**Category:** Operators

Bitwise exclusive OR: keep bits set on exactly one side.

## Syntax

```basic
left XOR right
```

## Parameters

- Operands: numeric expressions.

## Use cases

- Build arithmetic formulas or conditions.
- Trace how operands change the result.

## Examples

### Example 1 (program)

```basic
10 PRINT 6 XOR 3
```

Expected output / effect:

```text
 5 
```

## Notes

- This is bitwise XOR, not exponentiation; use ^ for powers.
