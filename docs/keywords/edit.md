# EDIT

**Status:** Not implemented - reference only  
**Category:** Environment

Request editing of a numbered line in supporting classic interpreters.

## Syntax

```basic
EDIT line
```

## Parameters

- line: existing source line.

## Use cases

- Change a stored line.

## Examples

### Example 1 (reference)

```basic
EDIT 20
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
- Currently edit the source directly in the ASCII IDE.
