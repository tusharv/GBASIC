# WINDOW

**Status:** Not implemented - reference only  
**Category:** Graphics

Map logical graphics coordinates onto the viewport.

## Syntax

```basic
WINDOW (x1,y1)-(x2,y2)
```

## Parameters

- Coordinates: logical coordinate bounds.

## Use cases

- Draw a graph in mathematical coordinates.

## Examples

### Example 1 (reference)

```basic
WINDOW (-10,-10)-(10,10)
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
