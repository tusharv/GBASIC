# LOG

**Status:** Supported  
**Category:** Functions

Calculate the natural logarithm (base e).

## Syntax

```basic
LOG(number)
```

## Parameters

- number: positive numeric expression.

## Use cases

- Explore exponential growth inverses.

## Examples

### Example 1 (program)

```basic
10 PRINT LOG(1)
```

Expected output / effect:

```text
 0 
```

## Notes

- Zero and negative arguments raise Illegal function call. For another base use LOG(x)/LOG(base).
