# CALL

**Status:** Not implemented - reference only  
**Category:** Procedures

Invoke a named SUB procedure.

## Syntax

```basic
CALL name [(arguments)]
```

## Parameters

- name: a declared or defined SUB.
- arguments: values or variables matching its parameters.

## Use cases

- Run a reusable procedure.

## Examples

### Example 1 (reference)

```basic
CALL Greet("Ada")
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
