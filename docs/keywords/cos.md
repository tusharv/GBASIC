# COS

**Status:** Supported  
**Category:** Functions

Calculate the cosine of an angle in radians.

## Syntax

```basic
COS(angle)
```

## Parameters

- angle: numeric radians.

## Use cases

- Calculate a circular horizontal coordinate.

## Examples

### Example 1 (program)

```basic
10 PRINT COS(0)
```

Expected output / effect:

```text
 1 
```

## Notes

- Use radians; trigonometric values are approximate.
