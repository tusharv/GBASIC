# PAINT

**Status:** Not implemented - reference only  
**Category:** Graphics

Flood-fill a graphics region from a seed point.

## Syntax

```basic
PAINT (x,y) [, paint [, border]]
```

## Parameters

- x/y: seed point.
- paint/border: fill and boundary colors.

## Use cases

- Color the inside of a closed shape.

## Examples

### Example 1 (reference)

```basic
PAINT (80,60), 2, 4
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
