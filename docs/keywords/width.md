# WIDTH

**Status:** Not implemented - reference only  
**Category:** Terminal layout

Set legacy text dimensions or a supported device's output width.

## Syntax

```basic
WIDTH columns [, rows]
```

## Parameters

- columns/rows: supported text mode dimensions.

## Use cases

- Request an 80-column screen.

## Examples

### Example 1 (reference)

```basic
WIDTH 80, 25
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
