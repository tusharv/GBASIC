# SYSTEM

**Status:** Supported  
**Category:** Environment

Exit the programming environment.

## Syntax

```basic
SYSTEM
```

## Parameters

- No arguments.

## Use cases

- Leave the prompt or close the IDE.

## Examples

### Example 1 (shell)

```basic
SYSTEM
```

Expected output / effect:

```text
The environment exits.
```

## Notes

- The UI checks unsaved work. The prompt exits immediately. QUIT and EXIT are aliases.
