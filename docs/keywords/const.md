# CONST

**Status:** Not implemented - reference only  
**Category:** Variables

Define a named constant rather than a mutable variable.

## Syntax

```basic
CONST name = constant-expression
```

## Parameters

- name: constant identifier.
- constant-expression: value evaluated for the declaration.

## Use cases

- Give a fixed formula parameter a readable name.

## Examples

### Example 1 (reference)

```basic
CONST PI = 3.14159
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
- Currently use a normal assignment and avoid changing that variable by convention.
