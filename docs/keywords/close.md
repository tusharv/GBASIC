# CLOSE

**Status:** Not implemented - reference only  
**Category:** Files

Close one or more BASIC file handles.

## Syntax

```basic
CLOSE [#number [, #number ...]]
```

## Parameters

- number: optional open file handle; no handles traditionally closes all.

## Use cases

- Finish file work and release resources.

## Examples

### Example 1 (reference)

```basic
CLOSE #1
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
