# WRITE

**Status:** Not implemented - reference only  
**Category:** Input/output

Output values in a delimited representation suitable for reading back.

## Syntax

```basic
WRITE expression [, expression ...]
```

## Parameters

- expressions: numeric or string fields.

## Use cases

- Produce comma-separated output.

## Examples

### Example 1 (reference)

```basic
WRITE "Ada", 10
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
