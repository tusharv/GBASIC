# VIEW

**Status:** Not implemented - reference only  
**Category:** Graphics

Set a graphics viewport or text window using dialect-specific forms.

## Syntax

```basic
VIEW (x1,y1)-(x2,y2)
```

## Parameters

- Coordinates: viewport bounds; optional fill/border forms depend on dialect.

## Use cases

- Restrict drawing to a region.

## Examples

### Example 1 (reference)

```basic
VIEW (10,10)-(100,100)
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
