# INKEY$

**Status:** Not implemented - reference only  
**Category:** Keyboard

Poll for an available key without waiting for a full input line.

## Syntax

```basic
INKEY$
```

## Parameters

- No arguments; returns an empty string when no key is available.

## Use cases

- React to keys in a game loop.

## Examples

### Example 1 (reference)

```basic
K$=INKEY$
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
