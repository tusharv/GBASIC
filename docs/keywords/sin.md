# SIN

**Status:** Supported  
**Category:** Functions

Calculate the sine of an angle in radians.

## Syntax

```basic
SIN(angle)
```

## Parameters

- angle: numeric radians, not degrees.

## Use cases

- Model periodic motion.

## Examples

### Example 1 (program)

```basic
10 PRINT SIN(0)
```

Expected output / effect:

```text
 0 
```

## Notes

- For degrees, multiply by pi/180 before calling. Floating-point approximation applies.
