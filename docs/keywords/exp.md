# EXP

**Status:** Supported  
**Category:** Functions

Calculate e raised to a numeric power.

## Syntax

```basic
EXP(number)
```

## Parameters

- number: exponent.

## Use cases

- Explore continuous exponential growth.

## Examples

### Example 1 (program)

```basic
10 PRINT EXP(0)
```

Expected output / effect:

```text
 1 
```

## Notes

- Large arguments may raise Overflow. This is not 10 raised to a power.
