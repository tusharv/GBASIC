# +

**Status:** Supported  
**Category:** Operators

Add two numbers, or concatenate two strings.

## Syntax

```basic
left + right
```

## Parameters

- Operands: two numbers or two strings.

## Use cases

- Build arithmetic formulas or conditions.
- Trace how operands change the result.

## Examples

### Example 1 (program)

```basic
10 PRINT 2+3;"A"+"B"
```

Expected output / effect:

```text
 5 AB
```

## Notes

- Both operands must be numeric or both strings; implicit numeric-to-string conversion is not performed.
