# RESUME

**Status:** Not implemented - reference only  
**Category:** Errors

Resume execution after a handled error.

## Syntax

```basic
RESUME
RESUME NEXT
RESUME line
```

## Parameters

- Optional NEXT or line determines where execution continues.

## Use cases

- Recover after an ON ERROR handler.

## Examples

### Example 1 (reference)

```basic
RESUME NEXT
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
