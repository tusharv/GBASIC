# DRAW

**Status:** Not implemented - reference only  
**Category:** Graphics

Interpret a compact graphics drawing-command string.

## Syntax

```basic
DRAW command$
```

## Parameters

- command$: legacy movement, direction, color and scale commands.

## Use cases

- Draw a small vector shape from text commands.

## Examples

### Example 1 (reference)

```basic
DRAW "R20D20L20U20"
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
