# NAME

**Status:** Not implemented - reference only  
**Category:** Files

Rename a file in a supporting BASIC filesystem.

## Syntax

```basic
NAME "old" AS "new"
```

## Parameters

- old/new: source and destination paths.

## Use cases

- Rename an output file.

## Examples

### Example 1 (reference)

```basic
NAME "old.txt" AS "new.txt"
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
