# ABS

**Status:** Supported  
**Category:** Functions

Return the nonnegative magnitude of a number.

## Syntax

```basic
ABS(number)
```

## Parameters

- number: numeric expression.

## Use cases

- Find an absolute difference.

## Examples

### Example 1 (program)

```basic
10 PRINT ABS(-7)
```

Expected output / effect:

```text
 7 
```

## Notes

- ABS removes a negative sign; it does not round.
