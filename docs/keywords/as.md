# AS

**Status:** Not implemented - reference only  
**Category:** Types

Specify a declared type in QBasic declarations or procedure signatures.

## Syntax

```basic
DIM name AS type
```

## Parameters

- name: declared variable.
- type: a supported QBasic type or a user-defined record.

## Use cases

- Declare a variable type explicitly.

## Examples

### Example 1 (reference)

```basic
DIM COUNT AS INTEGER
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
