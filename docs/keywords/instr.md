# INSTR

**Status:** Not implemented - reference only  
**Category:** Strings

Find the one-based location of a substring.

## Syntax

```basic
INSTR([start,] text$, find$)
```

## Parameters

- start: optional starting position.
- text$: source string.
- find$: substring to locate.

## Use cases

- Find a delimiter in text.

## Examples

### Example 1 (reference)

```basic
PRINT INSTR("BASIC", "SI")
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
