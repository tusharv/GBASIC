# LINE

**Status:** Not implemented - reference only  
**Category:** Graphics

Draw a line or rectangular box in a graphics mode.

## Syntax

```basic
LINE (x1,y1)-(x2,y2) [, color] [, B | BF]
```

## Parameters

- Coordinates: line endpoints or opposite box corners.
- B: outline box; BF: filled box.

## Use cases

- Draw a border or rectangle.

## Examples

### Example 1 (reference)

```basic
LINE (10,10)-(50,40), 4, B
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
