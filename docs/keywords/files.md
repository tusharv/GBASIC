# FILES

**Status:** Not implemented - reference only  
**Category:** Files

List matching files in the interpreter's filesystem view.

## Syntax

```basic
FILES ["pattern"]
```

## Parameters

- pattern: optional wildcard filter.

## Use cases

- Find a program to load.

## Examples

### Example 1 (reference)

```basic
FILES "*.BAS"
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
- Currently use the F3 examples dropdown to find the supplied programs.
