# MERGE

**Status:** Not implemented - reference only  
**Category:** Environment

Merge an ASCII numbered source file into a stored program.

## Syntax

```basic
MERGE "filename"
```

## Parameters

- filename: classic text BASIC source.

## Use cases

- Combine a program with a subroutine listing.

## Examples

### Example 1 (reference)

```basic
MERGE "library.bas"
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
