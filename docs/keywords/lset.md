# LSET

**Status:** Not implemented - reference only  
**Category:** Strings / files

Left-align text in an existing fixed-width string field.

## Syntax

```basic
LSET target$ = text$
```

## Parameters

- target$: existing destination field.
- text$: source text to align.

## Use cases

- Populate a fixed-width file field.

## Examples

### Example 1 (reference)

```basic
LSET NAME$ = "Ada"
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
