# DEFDBL

**Status:** Not implemented - reference only  
**Category:** Types

Set the default double-precision type for a letter range.

## Syntax

```basic
DEFDBL letter[-letter]
```

## Parameters

- letter range: variable-name initials.

## Use cases

- Use double-precision defaults in a module.

## Examples

### Example 1 (reference)

```basic
DEFDBL A-Z
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
