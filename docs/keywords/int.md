# INT

**Status:** Supported  
**Category:** Functions

Round down toward negative infinity.

## Syntax

```basic
INT(number)
```

## Parameters

- number: numeric expression.

## Use cases

- Count completed units or periods.

## Examples

### Example 1 (program)

```basic
10 PRINT INT(-1.2)
```

Expected output / effect:

```text
-2 
```

## Notes

- INT differs from FIX for negative non-integers.
