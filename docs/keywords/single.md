# SINGLE

**Status:** Not implemented - reference only  
**Category:** Types

Name QBasic's single-precision numeric type in declarations.

## Syntax

```basic
DIM name AS SINGLE
```

## Parameters

- name: single-precision numeric variable.

## Use cases

- Declare approximate fractional values.

## Examples

### Example 1 (reference)

```basic
DIM RATE AS SINGLE
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
- For currently supported variables, use suffixes %, !, # or $ instead of AS declarations.
