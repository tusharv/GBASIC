# CIRCLE

**Status:** Not implemented - reference only  
**Category:** Graphics

Draw a circle or arc in a graphics mode.

## Syntax

```basic
CIRCLE (x,y), radius [, color]
```

## Parameters

- x/y: center.
- radius: circle size.
- color: optional palette index; additional arc/aspect arguments exist in legacy dialects.

## Use cases

- Draw a circular object.

## Examples

### Example 1 (reference)

```basic
CIRCLE (80,60), 20, 4
```

## Notes

- Not implemented in Ghost BASIC. The example explains legacy syntax and cannot run here.
- This is a reference topic, not a promise of complete GW-BASIC/QBasic compatibility.
