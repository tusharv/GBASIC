# Graphics API and examples

Execute inline under the user's instruction to add graphics and examples.
Architecture: deterministic indexed-color framebuffer owned by Runtime; no native GUI
or new dependency. BASIC syntax delegates to the same public Graphics API. Explicit
CLI PNG output and an F9 terminal snapshot provide usable viewing paths.

Scope: SCREEN 0/7/9/12 (text, 320x200, 640x350, 640x480), fixed 16-color palette,
COLOR foreground/background, PSET/PRESET, LINE explicit endpoints and B/BF boxes,
CIRCLE full pixel-space circles, POINT(x,y), graphical CLS. All coordinates and radii
are signed-16-bit integers after BASIC rounding; colors 0..15. Offscreen drawing clips;
POINT outside returns -1. No arcs/aspect, STEP, implicit LINE start, style masks,
PAINT/DRAW, pages, text rasterization, palette changes or animation in this batch.
SCREEN resets colors/pixels; RUN resets to text mode, immediate execution preserves state.
